## Spacing Scale

Dùng Tailwind v4 default spacing scale (đã là multiples of 4). KHÔNG custom override — tránh phình config khi shadcn cập nhật.

| Token | Tailwind | px | Usage trong Phase 1 |
|-------|----------|-----|---------------------|
| xs | `gap-1` / `p-1` | 4px | Icon gap trong button (icon + label), badge inner padding |
| sm | `gap-2` / `p-2` | 8px | Compact form group, sidebar menu item internal gap |
| md | `gap-4` / `p-4` | 16px | Default card padding, form field vertical rhythm, topbar inner padding |
| lg | `gap-6` / `p-6` | 24px | Login card padding, sidebar section padding, page section gaps |
| xl | `gap-8` / `p-8` | 32px | Login screen vertical center spacing, breadcrumb-to-content gap |
| 2xl | `gap-12` / `p-12` | 48px | Empty state major separator, 404/500 hero block top margin |
| 3xl | `gap-16` / `p-16` | 64px | (rarely used in M0; reserved cho dashboard hero spacing M6) |

**Layout primitives lock cho M0:**
- **Sidebar width:** `w-64` (256px) khi expand, `w-16` (64px) khi collapse — shadcn `sidebar` block default
- **Topbar height:** `h-14` (56px) — shadcn `sidebar` default, đủ chỗ chứa breadcrumb + user dropdown + bell
- **Breadcrumb row height:** `h-10` (40px), `px-6 py-2`
- **Login card max-width:** `max-w-md` (448px), `p-8`
- **Min page width target:** 1366px (laptop baseline); mobile breakpoint `md:` 768px (sidebar collapse vào `Sheet`)
- **Touch target minimum:** 44×44px (button `h-10` + `px-4` đạt chuẩn AA)

**Exceptions:** `h-14` topbar (56px = 4×14) là multiple of 4 hợp lệ; `w-64` sidebar (256px) là 4×64.

## Typography

Be Vietnam Pro với 3 trọng số (400 regular, 600 semibold, 700 bold). Line-height tuân thủ: body 1.5, heading 1.2.

**Type scale — 4 sizes (đúng max dimension rule):**

| Role | Tailwind class | Size (px) | Weight | Line Height | Usage trong Phase 1 |
|------|---------------|-----------|--------|-------------|---------------------|
| Body | `text-sm` | 14 | 400 | 1.5 (20px) | Form label, sidebar menu item, table row content, body copy mặc định, field hint, breadcrumb separator label, footer caption, helper text |
| Body emphasis | `text-sm font-semibold` | 14 | 600 | 1.5 | Active sidebar item, button label, breadcrumb current page, card title nhỏ |
| Subheading / H4 | `text-base` | 16 | 600 | 1.4 (22px) | Card title, dialog title, section header |
| Heading / H2 | `text-2xl` | 24 | 600 | 1.2 (29px) | Page title (vd "Đăng nhập", "Trang chủ"), 404/500 heading |
| Display / H1 | `text-4xl` | 36 | 700 | 1.2 (43px) | Login screen brand line, 404/500 hero number "404" / "500" |

**Final scale tổng kết:** **14 / 16 / 24 / 36 = 4 sizes** | **400 / 600 / 700 = 3 weights**

> **Waiver — 3 weights cho gov VN context:**
> Strict dimension rule là max 2 weights, nhưng Phase 1 dùng 3 weights (400 body / 600 emphasis / 700 display) — exception có chủ đích cho hierarchy formal gov VN, không phải scale 2 weights chuẩn dimension rule.
>
> **Lý do:**
> 1. Tiếng Việt với dấu (sắc, huyền, ngã, hỏi, nặng + dấu mũ ô/â/ê + đ/Đ) cần weight gradient rõ hơn để đọc tốt — gap 400 ↔ 600 không đủ tách bạch giữa body và display heading.
> 2. Gov VN tone formal cần emphasis tách biệt body và heading display — page title (24px/600) không thể hùng hồn bằng hero number "404" / "500" (36px/700) nếu cùng weight.
> 3. Tránh font-medium 500 (đã loại bỏ) để giữ contrast clear giữa các bậc.

**Quy tắc Vietnamese rendering:**
- Font Be Vietnam Pro render đầy đủ dấu (`̀`, `̂`, `̆`, `̛`, `̣`, `đ`, `Đ`) đúng — đã verify trong research STACK.md §5
- KHÔNG dùng `font-feature-settings: "ss01"` hay alt typeface vì Vietnamese diacritics có thể vỡ
- `font-smoothing: antialiased` áp dụng global trên `body` để dấu sắc/huyền không bị aliasing trên Windows
- Tránh `text-tracking` (letter-spacing) trên text tiếng Việt > 14px — dấu rời chữ
- KHÔNG dùng `text-xs` (12px) — đã loại bỏ khỏi scale; mọi caption/helper/footer/breadcrumb separator label dùng `text-sm` (14px)

**Tone of voice tiếng Việt (trong copy):**
- **Formal, respectful** — "Quý ông/Quý bà", "Vui lòng", "Xin mời"
- **Câu chủ động, không passive English-style** — "Mật khẩu chưa đúng" thay vì "Mật khẩu sai" (cộc lộc)
- **Honorific khi cần:** error → "Vui lòng kiểm tra lại tên đăng nhập hoặc mật khẩu", KHÔNG "Tên đăng nhập sai"
- **CTA động từ + danh từ:** "Đăng nhập", "Đăng xuất" — không "Submit" / "Logout"

## Color

Bảng màu căn theo VN government standard (FEATURES.md §5.1) với tinh chỉnh "Vercel-grade" 2026 — base slate (60%), card surface white (30%), accent navy blue cho gov VN (10%), kèm 5 màu trạng thái cho status badge sau này (lock từ M0 để mọi phase tái dùng).

| Role | Tailwind / HSL | Usage |
|------|----------------|-------|
| Dominant (60%) — Background | `bg-slate-50` = `hsl(210 40% 98%)` | Page background mặc định toàn app, login screen background |
| Secondary (30%) — Card / Sidebar | `bg-white` = `hsl(0 0% 100%)` cho card; `bg-slate-100` = `hsl(210 40% 96%)` cho sidebar | Card surface, dialog, sidebar panel, topbar |
| Border subtle | `border-slate-200` = `hsl(214 32% 91%)` | Card border, divider, breadcrumb separator |
| Text primary | `text-slate-900` = `hsl(222 47% 11%)` | Body text, heading |
| Text secondary | `text-slate-600` = `hsl(215 16% 47%)` | Helper text, breadcrumb non-current, sidebar inactive item |
| Text muted | `text-slate-500` = `hsl(215 16% 57%)` | Disabled state, placeholder |
| **Accent (10%) — Primary navy blue** | `bg-blue-700` = `hsl(217 91% 35%)` cho button & hover; `bg-blue-50` = `hsl(214 95% 96%)` cho active sidebar item bg | **Reserved-for list dưới đây** |
| Accent foreground | `text-white` trên blue-700 surfaces | Button text, active sidebar item label |

### Accent Reserved For (chỉ 7 elements trong Phase 1)

Accent navy blue (`blue-700`) CHỈ được dùng cho:

1. **Login screen primary CTA button** ("Đăng nhập") — `bg-blue-700 hover:bg-blue-800`
2. **Logo / brand mark** trong login + topbar — màu navy cho text "XTTMQG" + Quốc huy outline accent
3. **Sidebar active menu item** — `bg-blue-50 text-blue-700 border-l-2 border-l-blue-700`
4. **Breadcrumb hover state** trên link items — `hover:text-blue-700`
5. **Topbar notification bell** — icon `text-slate-600`, khi có badge đếm chuyển `text-blue-700` (không dùng red badge cho notification — red reserved cho destructive)
6. **Focus ring** trên input + button — `focus-visible:ring-2 focus-visible:ring-blue-700 focus-visible:ring-offset-2`
7. **Link inline trong body** — `text-blue-700 hover:underline` (vd "Quên mật khẩu?" link dưới password field)

**KHÔNG dùng accent blue cho:** hover overlay generic, divider, decorative element, illustration. Quy tắc 60/30/10 — accent xuất hiện <10% pixels trên screen.

## Layout Shell Contract (AUTH-06)

Dưới đây là contract chi tiết cho 3 component lớp ngoài (sidebar + topbar + breadcrumb) mà mọi page sau Phase 1 sẽ kế thừa.

### Sidebar (`AppSidebar`)

- **Component nguồn:** shadcn `sidebar` block (`npx shadcn add sidebar`)
- **Variant:** `inset` (sidebar floating với padding ngoài) — tạo cảm giác "Vercel-grade" hiện đại hơn `floating` hay `sidebar` cổ điển
- **Behavior:**
  - Desktop ≥ 1024px: collapsible giữa `w-64` expanded và `w-16` icon-only
  - Mobile < 1024px: hidden by default, mở qua hamburger trigger trên topbar → render trong shadcn `Sheet` overlay
  - Trạng thái collapse persist trong Zustand `useUIStore` + localStorage key `xttm-sidebar-collapsed`
- **Cấu trúc nội dung (Phase 1 chỉ render skeleton; menu items đầy đủ ở phase sau):**
  - Header (top, padding `p-4`): brand wordmark "XTTMQG" Be Vietnam Pro 18px weight 700 `text-blue-700` + chevron collapse trigger
  - Body (`flex-1 overflow-y-auto`): 2 section group — "Nghiệp vụ" (placeholder ở M0, sẽ thêm menu items từ M1+) và "Quản trị" (placeholder)
  - Footer (`p-4 border-t`): user mini block với avatar (32×32) + tên + role badge — click mở user menu (chung với topbar dropdown để consistent)
- **Active state:** `bg-blue-50 text-blue-700 border-l-2 border-l-blue-700` (left accent bar) — text dùng `text-sm font-semibold`
- **Hover state inactive:** `hover:bg-slate-100`
- **Icon-only mode (collapsed):** chỉ hiện icon (lucide), tooltip xuất hiện bên phải khi hover ≥ 700ms (shadcn `Tooltip`)

**Phase 1 chỉ cần render skeleton sidebar với 1 menu item placeholder "Trang chủ"** — đầy đủ menu render động sẽ làm ở Phase 2 trở đi qua `getMenuItems(role)` từ `lib/permissions.ts`.

### Topbar (`AppTopbar`)

- **Height:** `h-14` (56px) sticky top, `bg-white border-b border-slate-200`

## Accessibility Contract (lock từ M0)

Theo CLAUDE.md §8.2: keyboard nav + focus visible + AA contrast.

- **Focus ring:** `focus-visible:ring-2 focus-visible:ring-blue-700 focus-visible:ring-offset-2` trên mọi interactive (input, button, link, sidebar item, dropdown trigger)
- **Tab order trong login form:** Username → Password → Show/hide toggle → Đăng nhập button → SSO button
- **Skip link:** "Bỏ qua đến nội dung chính" (visually hidden until focused) — render đầu `(app)/layout.tsx` link tới `#main-content`
- **Aria labels** cho icon-only buttons (đã lock trong Copywriting Contract): notification bell, sidebar collapse, password show/hide
- **Role announcements:** Sonner toast dùng `role="status"` cho info/success, `role="alert"` cho error/warning
- **Color contrast verification (AA = 4.5:1 cho text):**
  - `text-slate-900` (#0F172A) trên `bg-white` (#FFF) = 16.4:1 ✓
  - `text-slate-600` (#475569) trên `bg-white` = 7.5:1 ✓
  - `text-white` trên `bg-blue-700` (#1D4ED8) = 7.7:1 ✓
  - `text-blue-700` trên `bg-blue-50` (#EFF6FF) = 8.9:1 ✓
- **Min font size:** 14px (`text-sm`) — đã loại bỏ 12px caption khỏi scale, tránh đọc khó cho lãnh đạo lớn tuổi
- **Keyboard shortcuts (lock cho phase sau, KHÔNG implement Phase 1):** Cmd+K command palette role-switch ở M7
