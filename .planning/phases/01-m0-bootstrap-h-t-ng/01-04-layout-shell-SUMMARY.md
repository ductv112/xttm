## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] getInitials TypeScript noUncheckedIndexedAccess errors**

- **Found during:** Task 2 typecheck
- **Issue:** `tsconfig.json` strict mode với `noUncheckedIndexedAccess: true` (Plan 01) → `parts[0]` và `parts[parts.length-1]` typed as `string | undefined`. Plan-defined code `parts[0][0]` và `parts[parts.length-1][0]` fail với 5 TS2532 errors ("Object is possibly 'undefined'").
- **Fix:** Refactor getInitials để handle undefined safely: filter(Boolean) loại empty strings + early-return on `!first` + `?? first` fallback for last + `charAt(0)` thay vì `[0]` index (charAt always returns string).
- **Files modified:** `components/layout/UserMenu.tsx`
- **Verification:** `npx tsc --noEmit` exit 0.
- **Committed in:** `8f8c74c` (Task 2 commit, fix inline)
